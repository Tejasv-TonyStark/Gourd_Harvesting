# Gourd_Harvesting
My friend has done a lot of hardwork i.e collected,labelled gourd dataset,the curiosity cameout by seeing his father struggle.So,as a collabartor my responsibilties include using CV and DL for autonomous Gourd harvesting!

## Project files

- `gourd_web_app/` contains the browser app and its exported models. Serve `gourd_web_app/dist/` over HTTP(S) to run it.
- `classification/` contains maturity-classification training and evaluation code.
- `final_report/` contains the final metrics, plots, and selected trained weights.
- The root Python scripts and training-result summaries cover detection and the two-stage pipeline.

The collected and labelled gourd dataset is private and is not included in this repository. Training and test scripts that require it need a local copy supplied separately. Sample images, labels, and per-image predictions are also excluded.
